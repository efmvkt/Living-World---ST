# 🌍 Living World

Расширение для SillyTavern: следит за героем и миром вокруг него, чтобы жизнь в истории шла и без тебя. Данные хранятся в самом чате, у каждой истории свой мир.

## Возможности

- **Герой**: настроение, чувства, мысли, что показывает и скрывает, мечты, любимое и нелюбимое, где он сейчас
- **Быт**: энергия, сытость, самочувствие, счастье, стресс, влечение, одежда, привычки и ресурсы
- **Дела**: собственное расписание и дела героя, а не задания игроку
- **Мир**: живые NPC со своими целями, тренды мира и сводка «Пока вас не было» при скачках времени
- **Календарь, газета-сплетник и архив концовок**
- **Снимки состояния**: можно вернуть мир на любой ход после отката чата
- **Сборка по истории**: мир сам расписывает события по последним N сообщениям чата

Состояние героя и мира подмешивается в промпт короткой строкой, так что персонаж ведёт себя по своему расписанию и состоянию. Для запросов можно выбрать отдельный профиль подключения (дешёвую модель).

## Установка

В SillyTavern открой *Extensions → Install extension* и вставь ссылку на этот репозиторий.

## Заметки

- Работает лучше, если в ответах персонажа есть инфоблок `[IB]` со строкой `L: место | дата | время | погода`: так мир знает текущую дату
- Обновление идёт отдельным запросом раз в несколько ответов, интервал настраивается в ⚙
